# 去 AI 味提示词迭代记录

## 判读口径

- 绿色“人工特征”最好，比例越高越好。
- 橙色“疑似 AI”是中间档。
- 红色“AI 特征”最差，应优先降低。
- 不把“未发现明显人工创作特征”误记为通过，也不把疑似 AI 与 AI 特征合并。

## 朱雀逐段报告观察

- GPT 第一章总结果为人工特征 16.16%、疑似 AI 83.84%、AI 特征 0%；报告分为三段，AIGC 值依次为 0.7088、0.4525、0.6369（PDF 第 1 页）。
- 第二段是唯一绿色段：从“她声音不大，却说得很清楚”开始，到年轻人观察是否还有旁人起身为止（PDF 第 3—4 页）。
- 绿色段仍有常见缓冲表达、观察性比喻和身体反应，说明孤立词命中不足以判定 AI 味；更稳定的差异是动作—他人反馈—下一选择的因果接力、物件与空间持续参与、对白改变局面、旁观者通过选择显露态度、叙述判断受 POV 知识边界约束。
- 第一段较多静态铺陈，第三段较多替角色或旁观者解释动机、意义与生理链条（PDF 第 2—3、4—6 页）。因此第二轮提示词优先加强场景功能与可见反馈，不设置句长、对白、感官或身体反应配额。

## 后续轮次控制

1. 从同一个“提纲已完成、正文未生成”检查点开始。
2. 保持模型版本、供应商、推理等级、温度、用户规则、风格、章节细纲与字数预算一致。
3. 每轮只生成并检测第一章，记录人工特征、疑似 AI、AI 特征三个原始比例。
4. 同时人工检查是否出现电报体、动作清单、硬凑对白、机械同义词替换、人物声口变平或题材读感下降。
5. 每轮围绕一个明确假设替换或压缩提示词，不累计所有规则，不在一轮中同时修改流程。
6. 只有提示词迭代多轮后不能稳定改善，才考虑细化去 AI 工作流。
