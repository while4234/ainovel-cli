# 绘境 Visual Studio 使用说明

“绘境”是项目内的封面、插图和角色肖像工作区。它只使用一个全局
AI2API 图片网关；草稿、任务和图片归属于当前作品，不会写入其他项目。

## 配置图片网关

1. 在 Web 工作台打开一个项目，点击顶部的“绘境”。
2. 在右侧“AI2API 设置”中填写 Base URL、API Key、默认图像模型和超时。
3. 点击“保存设置”。已保存的 API Key 不会回显；API Key 留空会保留原值，
   只有勾选“明确清除已保存密钥”后保存才会删除它。
4. 点击“验证并发现”可读取网关的模型清单。该操作只验证配置和发现模型，
   不会生成图片。已验证、未验证或不可生成的模型会分别显示状态；只有注册表
   允许的模型与尺寸可用于生成。

网关配置是本机全局配置，项目仅记录所选模型等非敏感参数。页面和 API 响应
不会显示已保存的密钥。

## 创建与编辑草稿

1. 在“故事视觉”或“角色肖像”页签中点击草稿栏的“+”。
2. 选择作品类型和范围：封面只支持整本书；插图支持整本书、卷或章节；
   角色肖像必须选择角色。这里没有参考图、批量生成或图片编辑入口。
3. 选择提示词模型、图像模型和尺寸。封面与肖像默认选择最接近 2:3 的尺寸，
   插图默认选择最接近 16:9 的尺寸；切换图像模型时，无效尺寸会自动归一化。
4. 手工填写“图片提示词”，或点击“AI 草拟提示词（1 次调用）”。AI 结果仍可
   继续编辑。编辑会在 700 毫秒后串行自动保存；保存失败时页面停止自动重试，
   需要点击失败状态手动重试。

“AI 草拟提示词”会产生一次真实文本模型调用，但不会生成图片。如果故事资料在
AI 起草后发生变化，页面会显示来源过期提示；生成前须明确确认继续使用旧提示词，
也可以重新起草或改为手工提示词。

## 明确确认后生成一张图片

点击“生成 1 张图片”只会打开确认框，不会立刻调用网关。确认框会再次展示模型、
尺寸、范围和提示词摘要；只有点击最终的“确认并生成 1 张”才会进行一次可能计费的
真实图片调用。系统固定一次生成一张，不会隐藏批量提交，也不会自动重试失败或
交付状态不明的调用。

“任务状态”只轮询当前活动任务；任务成功或失败后会刷新草稿和图库。安全错误信息
会给出可执行建议，不会展示网关的原始上游响应。

## 管理图库

- “预览”在页面内查看项目图片。
- “下载”通过当前项目的受控内容接口获取 Blob 文件，不会跳转到网关地址。
- “复用参数”新建草稿，复制不可变的模型、尺寸、范围和提示词参数；不会立即生成。
- “应用”把图片设置为对应封面、插图或肖像的当前素材。
- 已应用图片在图库中预览的是按用途归一化后的裁剪/留白版本；“下载”仍下载不可变
  原图。可点击“取消应用”解除当前引用，原图仍留在图库，随后才可删除。
- “删除图片”只删除未被应用引用的素材；正在使用的图片受保护，必须先更换或取消
  对它的引用。
- 草稿和图库使用游标分页，“加载更多”会保留已经展开的内容。

地址栏会保存 `projectId`、`view` 和 `draft`，刷新后可恢复当前项目、故事/角色页签
和草稿。切换项目或离开绘境时若仍有未保存内容，页面会先请求确认。

## 封面、角色与项目生命周期

- 当前应用的整本书封面会进入 EPUB 导出；未应用封面时仍使用原有文字封面页。
- 当前应用的角色肖像会按稳定角色 ID 展示在“设定中心 → 角色卡”，只作为图片投影，
  不会修改角色姓名、职责、描述或其他 StoryFoundation 正文。
- 普通项目克隆会复制当前绘境草稿、历史、原图、应用指针和衍生图，但不会重放复制
  过来的排队/运行生成任务。
- “重新规划”的新项目不会激活旧图片；旧 `output/artwork` 只保存在该项目的只读
  legacy reference 中。项目进入回收站、恢复或清空回收站时，绘境目录跟随完整项目树。
- 备份和手工恢复必须复制完整 `output/artwork`，不要只复制 JSON 或 `images/`。

## 哪些操作会调用真实服务

| 操作 | 真实文本模型 | 真实图片网关 | 可能计费 |
| --- | --- | --- | --- |
| 保存网关设置 | 否 | 否 | 否 |
| 验证并发现模型 | 否 | 是，仅 `GET /v1/models` | 通常否 |
| 手工编辑、自动保存、预览、下载、复用、应用、删除 | 否 | 否 | 否 |
| AI 草拟提示词 | 是，一次 | 否 | 可能 |
| 打开生成确认框 | 否 | 否 | 否 |
| 最终确认生成一张 | 否 | 是，一次图片生成 | 是 |

自动化测试只使用 localhost fake backend 和固定图片夹具，不验证真实网关，也不会
点击真实的最终付费确认。

当前 v1 不包含参考图、图片编辑、分镜、批量生成、自动章节插图插入或部署到其他环境。
